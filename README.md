# 🛒 SG Food City - Management System
A complete supermarket management system developed as Final Project for HNDIT @ SLIATE.

### ✨ Features
- Admin, Cashier & Security Dashboards
- Product & Stock Management
- Billing System
- User Role Management

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL (schema.sql)

### ⚙️ How to Run
1. Clone: `git clone https://github.com/Yasintha-Madhusanka/SG-FoodCity-Management-System.git`
2. Move to `htdocs` folder in XAMPP
3. Import `schema.sql` to phpMyAdmin
4. Run: `http://localhost/SG-FoodCity-Management-System`
